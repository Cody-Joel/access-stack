SYSTEMS / BUILD LOG

Windows installer prepared; installation still pending

The next Windows installation starts from Ubuntu. The recent preparation record shows Ventoy 1.1.17 installed on the USB and Win11_25H2_English_x64_v2.iso copied onto it. The file was listed at 7.9 GB, a SHA-256 was recorded, and the USB was safely unmounted.

That is the installer preparation milestone. It does not establish that Windows has been installed or that the machine has passed its first boot. The next step is to check the current disk layout before selecting an installation destination.

The goal remains to preserve Ubuntu and the existing Windows files. Older partition records are useful context, but they are not a substitute for a fresh disk check. Installation results will be added after they are verified.

SYSTEMS / INVESTIGATION

NVIDIA dependencies: keep the repair evidence

The Ubuntu graphics repair is still an open investigation. The remaining checks in the recent record concern package ownership, installed reverse dependencies and a simulated removal of two conflicting packages.

The useful distinction is between a proposed command, its actual output and a confirmed result. A removal simulation is a review step; it does not remove packages or demonstrate a successful repair.

This entry records the investigation status. A final fix will include the relevant package versions and verification output once those results are available.

STUDIO / PLANNING

Turning Access Stack into a focused business

Access Stack brings together software projects, systems experiments and development notes. The next step is to turn that work into a small, understandable offer that a customer can evaluate.

The working direction is practical websites and software workflows for individuals and small businesses, with independent software developed alongside service work. The scope and pricing still need validation with prospective customers.

The immediate planning work is to choose an initial service, demonstrate what it includes and connect each proposed expense to delivering that service. Research projects and concept visuals remain part of the studio, with their status made clear.
